# 검증 기록

검증일: 2026-11-05. 원격 Linux 서버의 Node.js 24.13.0에서 수행했습니다.

## 자동 검사

`npm run check`의 JavaScript 문법 검사와 자격증명 패턴 검사를 통과했습니다.
`npm test`의 21개 테스트를 모두 통과했습니다. 테스트는 별도 임시 DB와 AI 비활성 설정을 사용합니다.

- 두 잔 중 하나의 온도만 변경하며 총 수량과 기존 줄 유지
- 서로 다른 입력 연산의 동일 장바구니 사용, 같은 옵션 합치기
- 알 수 없는 메뉴·품절·불가능한 온도·유효하지 않은 수량 거절
- 여러 연산 중 오류가 나면 기존 상태 보존
- 환경변수·Git·런타임 파일의 HTTP 접근 차단
- 교차 출처 변경 요청과 운영자 무인증 요청 차단
- 가상 매장 프리셋 가입과 HttpOnly 세션
- 가상 월 구독 변경과 중복 요청 처리, 실제 청구 없음
- 오래된 revision 거절, 클라이언트가 제시한 가격 무시
- 최종 금액 재검증, 중복 주문 방지, 다른 매장 주문 접근 거절
- 가격·품절 변경 후 최종 확정 시 다시 검증
- AI 연결 없음 안내와 장바구니 보존
- 해당 매장의 운영 화면으로 도움 요청 전달
- 가상 계정 삭제 시 관련 세션·키오스크 접근 제거
- 글자·이미지의 개별 확대·축소, 크기 경계와 기본값 복원
- 한국어·영어·일본어·중국어 표시 요청과 메뉴명
- 주문이 섞인 문장을 화면 전용 요청으로 잘못 소비하지 않음
- 기존 크게 보기 설정의 이전과 잘못 저장된 설정의 보정

## 실제 OpenAI 연결

서버의 기존 키를 사용했습니다. 비밀값을 출력하거나 로컬 작업 사본으로 복사하지 않았습니다.

1. `따뜻한 아메리카노 두 잔 주세요.` → 따뜻하게 2잔, 7,000원
2. `그중 하나만 차갑게 바꿔 주세요.` → 따뜻하게 1잔 + 차갑게 1잔, 7,000원
3. OS 음성 합성으로 만든 한국어 샘플을 앱의 전사 API에 전송 → `따뜻한 아메리카노 두 잔 주세요.`로 변환 확인
4. 중국어 UI에서 `Switch to English, make the text bigger, and add one iced latte.` → 영어 전환, 글자 115%→130%, 기존 아메리카노 두 잔 유지 + 아이스 라테 한 잔 추가, 총 11,200원

실제 사람의 마이크 녹음이나 다양한 장애·발화 특성을 대상으로 한 음성 성능 평가가 아닙니다.

## Chrome 주요 흐름

- 서비스 사이트 → 가상 매장 선택 → 체험 가입
- 월 구독 결제 데모의 실제 청구 금액 0원 표시와 운영 화면 연결
- 내 매장의 전용 키오스크 연결
- 키보드 Enter로 메뉴 옵션 창 열기, 온도·수량 선택
- 화면으로 담은 두 잔을 AI 문장으로 부분 수정
- 크게 보기와 고대비 동시 적용 중 주문 수량·금액 유지
- 사용자 최종 확인 후 주문번호 발급
- 운영 화면에서 같은 매장의 접수 주문과 7,000원 체험 금액 표시
- 태블릿 테두리 안의 메뉴·주문 영역, 메뉴명과 가격 표시 확인
- 한국어·영어·일본어·중국어 전환 중 기존 주문과 금액 유지
- “글씨 크게 보여줘”는 글자만 115%, “사진 크게 보여줘”는 이미지만 115%로 변경

데스크톱 화면 배치를 시각적으로 확인했습니다. 브라우저의 390px viewport 요청이 실제로 적용되지 않아 전용 모바일 렌더링 검증은 완료하지 못했습니다. 반응형 CSS는 포함되어 있으나 모바일 검증 완료로 주장하지 않습니다.

## 아직 하지 않은 검증

- 장애 당사자 사용자 테스트와 실제 스크린리더별 전체 여정 평가
- 실제 매장 소음·발화 다양성·마이크 하드웨어 환경 평가
- 실제 키오스크의 높이·촉각 조작부·물리적 접근성 인증
- 실제 결제·정식 계정 복구·POS 연동
- 공개 인터넷 서비스의 운영·보안·성능·법적 요구 전체 평가

자동 테스트와 소수의 기능 시연을 전체 이용자에 대한 접근성 보장·상용 운영 준비·사업 성과로 확대 해석하지 않습니다.
