# Open Kiosk

**Your pace. Your way.**

접근성 있는 주문 경험과 매장 운영자용 구독 서비스를 함께 검증하는 2인 대학 수업 프로젝트입니다.

> 현재 단계: 공개 저장소와 프로젝트 기획 문서 준비. 웹사이트·키오스크 앱·AI 연결은 아직 구현되지 않았습니다.
> Open Kiosk는 프로젝트 가칭이며, 이름의 상표·도메인 사용 가능 여부는 검증하지 않았습니다.

## 두 가지 제품 경험

| 서비스 | 이용자 | 목표 경험 |
| --- | --- | --- |
| 서비스 웹사이트 | 도입을 검토하는 점주·기관 | 문제와 제품 이해 → 데모 체험 → 운영자 가입 → 월 구독 결제 데모 |
| 키오스크 서비스 | 매장 방문 고객 | 가입 없이 음성·화면·키보드로 주문하고 잘못된 선택을 수정 |

**이 프로젝트의 결제 데모는 운영자가 우리 서비스를 구독하는 월 정액 결제입니다. 키오스크 이용 고객의 음식값 결제와 구분합니다. 실제 청구는 하지 않습니다.**

## 검증할 기술적 차별점

- 입력 방식을 바꿔도 장바구니·선택 옵션·진행 상황 유지
- 대화 맥락을 반영해 수량이나 옵션 등 필요한 항목만 수정
- 등록된 메뉴·가격·판매 가능 여부를 기준으로 주문 내용 검증
- 사용자의 최종 확인을 거쳐 주문 확정
- 키보드·스크린리더·큰 글씨 등 다양한 이용 방식 지원

위 내용은 구현 목표이자 검증할 가설입니다. 경쟁 서비스 전체에 없는 독점적 기능이나 검증된 접근성 성과를 뜻하지 않습니다.

## 프로젝트 범위

- 약 1주일 작업, 2인 팀, 노트북 발표
- 카페 1곳을 가정한 한국어 주문 시나리오
- 운영자용 서비스 사이트와 고객용 키오스크 체험 연결
- 회원가입·구독 결제는 교육용 데모
- 실제 개인정보·카드정보 입력을 요구하지 않는 데모 경험 목표
- 실제 상용 결제·POS 연동·접근성 인증은 후속 검증 범위

프로젝트라는 이유만으로 실제 개인정보 처리나 외부 서비스 이용에 관한 의무가 면제된다고 가정하지 않습니다.

## 공개 저장소 운영

API 키·환경변수 파일·실제 개인정보·음성 녹음·실제 주문 데이터는 커밋하지 않습니다.
가상 계정과 합성 데이터를 사용하고, 구현된 기능과 계획 중인 기능을 구분해 기록합니다.

현재 실행 가능한 앱이나 배포 주소는 없습니다. 구현이 시작되면 실행 방법과 검증 결과를 추가합니다.
