# Open Kiosk

**Your pace. Your way.**

접근성 있는 주문 경험과 매장 운영자용 구독 서비스를 함께 검증하는 2인 대학 수업 프로젝트입니다.

> 현재 단계: 서비스 사이트·구독 데모·운영 화면·키오스크 구현. 실제 OpenAI 주문 해석과 합성 음성 전사, 자동 테스트 32개 및 주요 브라우저 흐름 검증 완료. 실제 매장용 상용 서비스가 아닙니다.
> Open Kiosk는 프로젝트 가칭이며, 이름의 상표·도메인 사용 가능 여부는 검증하지 않았습니다.

## 두 가지 제품 경험

| 서비스 | 이용자 | 목표 경험 |
| --- | --- | --- |
| 서비스 웹사이트 | 도입을 검토하는 점주·기관 | 문제와 제품 이해 → 데모 체험 → 운영자 가입 → 월 구독 결제 데모 |
| 키오스크 서비스 | 매장 방문 고객 | 가입 없이 음성·화면·키보드로 주문하고 잘못된 선택을 수정 |

**이 프로젝트의 결제 데모는 운영자가 우리 서비스를 구독하는 월 정액 결제입니다. 키오스크 이용 고객의 음식값 결제와 구분합니다. 실제 청구는 하지 않습니다.**

## 검증할 기술적 차별점

- 입력 방식을 바꿔도 장바구니·선택 옵션·진행 상황 유지
- 대화 맥락을 반영해 수량이나 옵션 등 필요한 항목만 수정
- 등록된 메뉴·가격·판매 가능 여부를 기준으로 주문 내용 검증
- 사용자의 최종 확인을 거쳐 주문 확정
- 키보드·스크린리더·큰 글씨 등 다양한 이용 방식 지원
- 태블릿 형태의 체험 화면, 한국어·영어·일본어·중국어 UI
- 음성 인식 후 보내기 버튼 없이 요청 자동 반영, 마지막 주문 확정은 직접 확인
- 홈페이지의 31초 연속 음성 시연 영상: 글자·그림 140% 확대 → 아이스 두 잔 → 한 잔만 따뜻하게 → 차가운 잔에 헤이즐넛 시럽
- 주문만 바꾸는 AI 응답이 사용자의 확대·언어 설정을 초기화하지 않도록 서버에서 제한
- 헤이즐넛 시럽 옵션의 잔별 적용·제거와 서버 가격 계산
- 글자와 메뉴 이미지를 각각 조절. “글씨 크게 보여줘” 같은 화면 요청과 주문을 함께 처리

위 기능은 데모에 구현했습니다. 경쟁 서비스 전체에 없는 독점적 기능이나 장애 당사자에게 검증된 접근성 성과를 뜻하지 않습니다.

## 프로젝트 범위

- 약 1주일 작업, 2인 팀, 노트북 발표
- 카페 1곳을 가정한 한국어 주문 시나리오
- 운영자용 서비스 사이트와 고객용 키오스크 체험 연결
- 회원가입·구독 결제는 교육용 데모
- 실제 개인정보·카드정보 입력을 요구하지 않는 데모 경험 목표
- 실제 상용 결제·POS 연동·접근성 인증은 후속 검증 범위

프로젝트라는 이유만으로 실제 개인정보 처리나 외부 서비스 이용에 관한 의무가 면제된다고 가정하지 않습니다.

## 공개 저장소 운영

API 키·환경변수 파일·실제 개인정보·음성 녹음·실제 주문 데이터는 커밋하지 않습니다.
가상 계정과 합성 데이터를 사용하고, 구현된 기능과 계획 중인 기능을 구분해 기록합니다.

## 실행

Node.js 24.13 이상이 필요합니다. 외부 npm 패키지를 설치하지 않고 Node 내장 HTTP·SQLite·fetch를 사용합니다. 이 Node 버전에서 SQLite 모듈은 실험적 기능입니다.

```sh
cp .env.example .env
# 서버의 .env에 OPENAI_API_KEY를 설정합니다. 값을 Git이나 채팅에 올리지 마세요.
chmod 600 .env
npm start
```

기본 주소는 http://127.0.0.1:4188 입니다. 키가 없으면 메뉴판·키보드 조작과 운영·구독 데모는 작동하고, AI 입력에는 연결 준비 안내가 표시됩니다. AI를 사용한 것처럼 꾸미지 않습니다.

```sh
npm run check
npm test
```

테스트는 임시 데이터베이스와 AI 비활성 모드로 실행해 실제 키나 체험 데이터에 접근하지 않습니다.

## 서버와 접속

서버에서 `scripts/open-kiosk.service`를 사용자 systemd 서비스로 설치할 수 있습니다. 기본 바인딩은 루프백입니다. 발표 노트북에서는 SSH 포트 포워딩으로 접속합니다.

```sh
ssh -N -L 8418:127.0.0.1:4188 YOUR_SERVER_ALIAS
```

그 후 http://localhost:8418 을 엽니다. 서버 주소·사용자명·SSH 키 경로는 공개 저장소에 기록하지 않습니다. 공개 인터넷 배포 시에는 HTTPS·외부 접근 정책·과금 남용 방지·운영 절차를 별도로 검토해야 합니다.

구독은 운영자에게 제공되는 월 정액 **데모**입니다. 실제 카드정보 수집, 실제 청구·자동 갱신, 음식값 결제, 실제 POS 연동은 없습니다.
